# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Type

This is an **Obsidian vault** - a personal knowledge management system using markdown files, not a traditional software codebase. The vault follows the "Second Brain" methodology by Tiago Forte (CODE method: Capture, Organize, Distill, Express).

## Directory Structure

The vault is organized using the **PARA method**:

- **APRENDIZADO - SEGUNDO CÉREBRO/** - Notes about productivity systems, Obsidian usage, and the Second Brain methodology
- **IA/** - Research and learning materials about AI frameworks and tools

## Content Focus

### AI Research (IA/)
- **Agno Framework** (Agno.md, Plano Aprendizado Agno.md): Multi-agent AI framework with AgentOS runtime
  - FastAPI-based control plane for agent orchestration
  - Teams, Workflows, Memory, Knowledge (RAG), Tools, MCP integration
  - Installation: `pip install agentos`
  - Run with: `agentos run`

- **MCP** (MCP.md): Model Context Protocol resources and links
- **BeautifulSoup** (BeautifulSoup.md): Web scraping library reference
- **RAG** (RAG.md): Retrieval-Augmented Generation notes

### Productivity Systems (APRENDIZADO - SEGUNDO CÉREBRO/)
- **CODE Method**: Capture, Organize, Distill, Express cycle for information processing
- **PARA Method**: Projects, Areas, Resources, Archive organizational structure
- **Obsidian Tips**: Dataview plugin usage and workflow optimization

## Working with This Vault

When adding or modifying notes:
1. Use proper Obsidian frontmatter with `tags` YAML field for categorization
2. Follow the PARA structure when determining note placement
3. Include source links for external references
4. The vault primarily contains Portuguese language content
